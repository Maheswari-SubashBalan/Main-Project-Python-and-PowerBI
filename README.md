# PROJECT TITLE:
## E-Commerce Order Sales Analysis

Data Analytics Final Project using **Python** and **Power BI**

---

## Description

This project analyses e-commerce order data to find sales patterns, customer behaviour, and delivery performance.

The workflow includes:
- Data cleaning and pre-processing using Python (Pandas)
- Exploratory Data Analysis (EDA) with Matplotlib and Seaborn
- Interactive dashboards in Power BI
- Business insights and recommendations

**Domain:** Sales & E-commerce / Retail Analytics  
**Dataset Source:** [Hugging Face – millat/e-commerce-orders](https://huggingface.co/datasets/millat/e-commerce-orders)  
**Timeline:** April 2024 – April 2025  
**Records:** 1000 rows, 15 columns (cleaned to 920 rows after removing duplicates)

---

## Problem Statement

- Clean messy real-world order data (missing values, duplicates, outliers)
- Find which product categories and customer segments drive the most revenue
- Evaluate delivery performance and marketing channel effectiveness
- Provide actionable business recommendations
